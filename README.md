# Raport kierowców M&D TRANS – wersja instalowana (PWA)

Ewidencja czasu pracy kierowców i raporty PDF / Excel / CSV (PL / EN / NL).

**Adres programu:** https://marwilxs.github.io/raport-md/

Instalacja na telefonie:
- **iPhone (Safari):** Udostępnij → *Do ekranu początkowego*
- **Android (Chrome):** menu ⋮ → *Zainstaluj aplikację*

Dane (wpisy, kierowcy, stawki) są przechowywane wyłącznie na urządzeniu – nic nie trafia na serwer.
Szczegóły: `INSTRUKCJA_Ins_phone.txt`.
